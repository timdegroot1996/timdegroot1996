## 📊 robotframework-dashboard

A CLI that reads Robot Framework `output.xml` files, stores them in a database and generates a
**single self-contained HTML dashboard** — trends, flaky tests, durations, comparisons — no server required.

[![Dashboard](https://raw.githubusercontent.com/MarketSquare/robotframework-dashboard/main/img/dashboard.png)](https://marketsquare.github.io/robotframework-dashboard/example/robot_dashboard.html)

```bash
pip install robotframework-dashboard
robotdashboard --outputpath output.xml
```

- 📖 [Documentation](https://marketsquare.github.io/robotframework-dashboard/) · 🧪 [Live example dashboard](https://marketsquare.github.io/robotframework-dashboard/example/robot_dashboard.html)
- 🤖 Robot Framework listener for automatic uploads, optional FastAPI server mode
- 🔌 Pluggable database backends (SQLite built in, MySQL/PostgreSQL via a custom class)
